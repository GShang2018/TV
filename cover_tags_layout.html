首页封面 Tag 布局位置说明

展示不同封面样式中各 tag 标签的位置分布

year ← vod_year
site ← Site.getName() (非vod字段)
remark ← vod_remarks
name ← vod_name (普通文字, 无tag背景)
1. 海报式封面 (VodRectHolder / VodPortraitHolder)
布局文件: adapter_vod_rect.xml / adapter_vod_portrait.xml — 全套标签

2022 泥巴 更新至第10集
蜘蛛人：英雄归来
2022 泥巴 更新至第10集
蜘蛛人：英雄归来
year = 左上角 (alignStart + alignTop)
site = 右上角 (alignEnd + alignTop)
remark = 左下角 (alignStart + alignBottom)
name = 封面图下方 (below image)
2. 横版小封面 (VodOneHolder)
布局文件: adapter_vod.xml — 无 year，有 progress 进度条

泥巴 更新至第10集
蜘蛛人：英雄归来
site = 左上角 (alignStart + alignTop)
remark = 进度条上方, 左下区域
progress = 底部进度条 (观看历史)
name = 封面图下方 (below image)
无 year 标签
3. 列表模式 (VodListHolder)
布局文件: adapter_vod_list.xml — 水平排列: 左图 + 右文

4. 圆形头像 (VodOvalHolder)
布局文件: adapter_vod_oval.xml — 最简样式，无任何 tag

image
← vod_pic
蜘蛛人
仅 image + name，无 year / site / remark 标签
汇总对比
标签 vod_xx 字段 Rect / Portrait One List Oval
year vod_year 左上角 — 布局有/未绑定 —
site Site.getName() 右上角 左上角 布局有/未绑定 —
remark vod_remarks 左下角 进度条上方 中间行 —
name vod_name 图下方 图下方 顶部 图下方居中
image vod_pic 封面图 封面图 左侧 圆形封面
带胶囊背景 (shape_vod_tag) 的标签：year、site、remark
name 为普通文字，无 tag 背景色。
点击跳转使用 vod_id，不在封面上显示。
